# Adding content

To add a project: copy `_templates/project.md` into `projects/`, rename it, fill in the frontmatter.

To add a piece of art: copy `_templates/art.md` into `art/`, rename it, fill in the frontmatter, and drop the image in `public/art/`.

`_templates/` itself is not read by either collection — only `projects/` and `art/` are.
